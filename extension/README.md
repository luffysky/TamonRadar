# TamonRadar 瀏覽器擴充(Chrome / Edge)

在任何網頁選取文字 → 右鍵「用 TamonRadar 搜尋」,或點工具列圖示輸入關鍵字,直接到 TamonRadar 搜尋比價。

## 安裝(開發者模式載入)
1. 開 `chrome://extensions`(Edge 是 `edge://extensions`)
2. 右上角開「開發人員模式」
3. 點「載入未封裝項目」,選這個 `extension/` 資料夾
4. 第一次使用點圖示,把「網站網址」設成你的前端網域(預設 `https://tamonradar.snowrealm.pet`)後儲存

## 功能
- 工具列彈窗:輸入關鍵字直接搜尋
- 右鍵選單:選取文字 → 一鍵搜尋
- 網址可自訂(存在瀏覽器同步儲存)

> 圖示可自行放 `icon16/48/128.png` 並在 manifest 的 action.default_icon 補上。
